# Personal Introduction Program

## Project Overview
This is a beginner-level Python project. It asks the user for their name, age, favorite hobby, and city, then displays a friendly welcome message.

## Objectives
- Learn Python variables.
- Practice input() and print().
- Understand strings and f-strings.
- Learn to run a Python program.

## Requirements
- Python 3
- VS Code or another text editor

## Setup Instructions
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run: `py personal_intro.py`
5. Enter your information when prompted.

## Code Structure
- `personal_intro.py`: Main Python program.
- `README.md`: Project documentation.
- `requirements.txt`: Project dependency information.
- `screenshot.png`: Screenshot of the program output.

## Technical Details
The program collects four inputs and stores them in variables. It uses strings and f-strings to display a personalized welcome message.

## Testing Evidence
**Test 1:** Enter a name, age, hobby, and city.

**Expected Result:** All information appears in the welcome message.

**Test 2:** Enter a different name and hobby.

**Expected Result:** The output updates to show the new information.
