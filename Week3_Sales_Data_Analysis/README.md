# Week 3: Sales Data Analysis

## Project Overview
A beginner-friendly Python and Pandas project that loads a sales CSV, explores the dataset, cleans missing values and duplicates, calculates sales metrics, and generates a Markdown report.

## Files
- `sales_analysis.py` – complete analysis program
- `sales_data.csv` – sample dataset with 100 rows and 5 columns
- `analysis_report.md` – generated report (created when the program runs)
- `requirements.txt` – required Python library
- `test_cases.txt` – simple validation checklist

## Setup
1. Install Python 3.
2. Open this folder in VS Code.
3. Open Terminal in VS Code.
4. Install dependencies:
   `python -m pip install -r requirements.txt`
5. Run:
   `python sales_analysis.py`

If `python` does not work on Windows, try:
`py -m pip install -r requirements.txt`
and
`py sales_analysis.py`

## Expected behaviour
The program prints dataset details, reports the cleaning summary, calculates revenue and product metrics, and creates/updates `analysis_report.md` in this folder.
