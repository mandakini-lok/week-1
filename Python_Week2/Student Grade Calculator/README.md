# Student Grade Calculator

## Project Overview
Student Grade Calculator is a Python-based project.
It calculates student grades based on marks entered
by the user.

## Objectives
- To calculate student grades.
- To understand if-elif-else statements.
- To use functions in Python.
- To validate student marks.
- To practice while loops and error handling.

## Features
- Accepts student name.
- Accepts marks between 0 and 100.
- Calculates grades automatically.
- Displays encouraging messages.
- Handles invalid inputs.

## Grading System

| Marks | Grade |
|-------|-------|
| 90-100 | A |
| 80-89 | B |
| 70-79 | C |
| 60-69 | D |
| 0-59 | F |

## Technologies Used
- Python
- Visual Studio Code

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open Terminal.
4. Run the command:

python grade_calculator.py

## Conclusion
This project helps us understand Python
programming concepts such as functions,
conditional statements, loops and error handling.
